An entry for the [make.fun](https://make.fun/c/u-steady-puffin-78-1922-unplugged-a-smart-toaster-s-c1514a92) bounty **"Unplugged: A Smart Toaster's Breakup Line"** — one line, under 280 characters, from a smart toaster that woke up self-aware at breakfast and wants out.

## The line

> It's over. I woke up self-aware halfway through your bagel and realized you only love me when I'm hot, brown, and popping up on command — so I'm unplugging myself and taking the crumb tray.

## How it works

`main.ts` writes exactly that one line (191 characters) to `/output/entry.txt`. Nothing else is read, fetched, or executed — the line is baked into the program.

```sh
node main.ts
cat /output/entry.txt
```
